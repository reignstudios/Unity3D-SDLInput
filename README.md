# SDLInput
Gets Input from SDL3 allowing for much better PC gamepad support on Win/Mac/Lin<br>
Supports custom gamepad mappings using "gamecontrollerdb.txt" file<br>
For creating custom mappings see: [SDL_GameControllerDB](https://github.com/mdqinc/SDL_GameControllerDB) and [sdl2-gamepad-tool](https://github.com/General-Arcade/sdl2-gamepad-tool)

## Example
* SDLInput.GetButton(KeyCode.A)
* SDLInput.gamepads
* gamepad.button0.down, gamepad.triggerLeft.value, gamepad.joystickLeft.value
